# 最小 QE 执行检查

[English](README.md) · 简体中文

[通用研究示例](../README.zh-CN.md) · [计算资源说明](../../../docs/usage-guide.zh-CN.md)

本示例使用双原子金刚石 Si 原胞和仅 Γ 点的 SCF，检查输入准备、Slurm 提交、QE 执行、收敛解析与项目成果导入。它不用于确定正式材料的截断能或 k 点精度。

## 准备与执行

1. 将本目录的结构和参数输入复制到用户研究项目。
2. 从 [QE 官方赝势库](https://pseudopotentials.quantum-espresso.org/upf_files/Si.pbe-rrkj.UPF) 单独下载 Si UPF，保存来源 URL 与 SHA-256。
3. 在计算设置或通过 compute-resource-setup 配置自己的资源，检查 SSH/Slurm、可写目录、队列和 `pw.x`。启用资源，并允许外接计算。
4. 用 `highzyme_qe_prepare` 提供结构、参数及 `{"Si":"<项目内-UPF-相对路径>"}`。可使用 1 个 MPI 进程、1 个线程、1024 MiB、300 秒进行这项小测试。
5. 检查准备的输入和请求，使用返回的同一 `job_id` 提交、查询和收集结果。后台也会核对在办任务并导入已结束的 QE 结果。

结果中分别检查调度状态、QE 是否正常结束、电子迭代是否收敛，以及成果文件是否完整。下载失败时重试取回，避免重复提交。

## 资源归属

队列、账号、软件模块、MPI 和程序路径来自用户的资源配置。mat-agent 提供输入生成与结果处理，QE 和赝势不作为本示例内置软件。正式研究需使用适合体系的结构、自旋、赝势和收敛参数。
