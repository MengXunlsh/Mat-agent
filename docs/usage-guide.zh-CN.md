# mat-agent 功能与使用说明

[English](usage-guide.md) · 简体中文

[程序首页](../README.zh-CN.md) · [合成示例](../examples/general-research/README.zh-CN.md)

本说明对应当前独立交付程序，按使用流程组织。基础模式为“通用研究”，案例可以采用通用研究、应用方向探索或材料候选设计；材料家族方法通过技能指导使用，没有另复制一套运行框架。

## 运行结构

DeepSeek Harness 负责对话、模型连接、计划、上下文压缩、文件和 Shell、持久终端、后台任务、子 Agent 及原生交互。mat-agent 插件负责项目科研状态、成果、授权和计算编排；Python 科学模块负责文档／结构解析、数值计算与图件生成。

```text
用户研究任务
  → 主 Agent：判断任务、按需计划并加载技能
  → 原生工具或科研工具／按需子 Agent
  → 保存输入、数值、代码、图件、报告与来源
  → 一项整组成果与 Git 版本
  → 案例引用或验证反馈
```

讨论和概念解释按问题回答；明确执行任务才开展相应操作。案例阶段组织研究内容，原生计划管理执行，不要求每个小任务走完整条流程。

## 第一次使用

从程序根运行 `scripts/start_workbench.ps1 -OpenBrowser`。默认端口 8790，可用 `-Port` 更换；关闭启动终端中的服务会停止本机 Web 进程。安装与依赖命令见[程序首页](../README.zh-CN.md)。

在“模型”设置中添加接口，并设置新会话默认模型；输入区的模型选择只影响当前会话，已有会话保留自己的选择。子 Agent 默认跟随主模型，必要时可单独配置。网页检索连接单独设置，更换聊天模型不会自动配置检索凭据。

从左侧添加真实本机目录作为项目。新建普通会话或案例继承当前／最近项目；尚未打开项目或缺少可用模型时，界面保留草稿并提示。建议将示例输入复制到独立研究目录后试用。

## 项目、会话、案例与成果

普通会话与案例在项目下同级。普通会话用于讨论、读资料、写代码或独立分析；案例增加目标、候选、证据与验证反馈，并拥有单独目录。

项目资源面板跟随当前项目，提供文件、成果、权限、任务、归档和记忆。文件页用于浏览、预览和编辑；成果页按一项研究结果组织报告、数据、图件、代码和来源。

“整理讨论为成果”调用原生子 Agent：主界面固定整理当前打开的会话／案例，默认最近 1 轮，可调整至最多 15 轮；项目成果页可选择同项目来源和具体消息。列表显示简短预览，整理使用选定消息的完整文本。草稿可编辑，保存后才成为正式成果；整理栏可以收起并保留未保存内容。

新成果文件使用小写英文关键词与连字符，标题与正文沿用用户语言。同一成果修订保持成果 ID 和路径；相同输入另做独立分析可使用“另建分析”或工具参数 `new_analysis=true`。已有成果的修订使用 `artifact_id`。图形布局或标签调整采用重绘，数值拟合结果保持原样。

## 权限与执行

| 位置 | 控制内容 |
|---|---|
| 项目资源 → 权限 | 项目文件／文件夹的使用和修改，成果整组文件授权 |
| 设置 → 执行权限 | Shell、联网、外接计算及新会话默认权限 |
| 会话原生权限选择器 | 只读、项目内修改、完整访问等模式 |

同项目会话、案例和子 Agent 使用同一套项目文件规则。指定资料、限制读写范围或关闭网络时，通用 Shell 会相应关闭；普通宿主进程不能同时承担逐文件、逐网络请求限制。文件工具仍按授权路径工作。项目记忆在资料读取范围受限时同步关闭。

权限变化控制后续读取；已明确发送到会话的内容保留在对话历史中。原生完整访问模式与项目明确设置的执行／内容规则共同生效。

## 版本、引用、归档与记忆

“版本”页按当前会话或案例展示 Git 节点、时间、说明和文件差异。恢复与撤销先预览影响，再产生新提交；后续修改冲突时会停止并提示。原生独立工作区可创建、切换、比较和合并，目录位于项目 `.agents/worktrees/`。

案例中的“引用此版本”固定成果整组文件及提交。原成果以后改变，已有引用仍读取原版本，用户主动更新引用后才切换。预览与后续工具输入使用同一固定版本；需要提供本地文件时，按需生成只读引用缓存。

项目归档页管理普通会话和案例，支持恢复、回收站与永久删除。永久删除会话／案例时保留已发布成果；删除案例文件夹为独立选项，Git 历史保留。处理运行中的任务后再进行删除。

项目记忆默认关闭。启用后 Agent 可以主动保存、检索和更新已采纳决定、偏好与方法，用户也可以查看、编辑或删除。记忆保存于 `.highzyme/memory.jsonl`，按项目隔离，使用关键词检索；完整研究报告仍作为成果保存。

## 科研技能与确定性工具

技能提供方法指导，工具承担结构化读取、数值运算和保存；Agent 负责理解任务、选择方法、解释与修订。输入 `/` 可选择技能，也可直接描述任务。

| 技能 | 用途 |
|---|---|
| literature-evidence | 从文献与补充资料形成材料、样品、测定及来源证据 |
| publication-retrieval | 按 DOI／PMCID／PMID 获取可访问正文、摘要或支持的补充材料 |
| assay-comparison | 对照选定测定的条件、数值、单位、来源和缺失项 |
| material-structure-check | 核对化学式、SMILES、分子／晶体／坐标文件 |
| initial-rate-kinetics | 底物浓度—初始速率的单组或多组 Michaelis–Menten 拟合 |
| formulation-calculations | 单位、配方、稀释、混合与投料比例计算 |
| signal-analysis | 标定拟合、样品反算、读出换算与荧光校正 |
| image-colorimetry | 图像选区、RGB／HSV 测量与选区标注 |
| reaction-simulation | 给定参数的反应模型与质量作用网络积分 |
| scientific-plotting | 统一科研图表、重绘和可编辑导出 |
| discussion-artifact | 将讨论整理成可修订的项目成果 |
| application-exploration | 从材料与证据提出应用方向、读出、对照和验证问题 |
| material-design | 结合材料家族方法提出有假设与判据的材料设计 |
| compute-resource-setup | 辅助配置用户计算连接、环境与最小执行测试 |
| scientific-computing | 准备和管理受支持的 QE 多步骤工作流 |

内置技能位于 `integrations/deepseek-harness/foundation/skills`。内部文献、分析和核查角色由原生子 Agent 按需执行；成果整理也使用原生子 Agent，复用同一模型与权限机制。

PDF／DOCX 可按页或文本块读取；扫描页需要渲染为图片并使用支持图像的模型。化学式／SMILES 使用身份工具；MOL/SDF 使用 RDKit，CIF/mmCIF/PDB 使用 Gemmi，XYZ/EXTXYZ/VASP/POSCAR/CONTCAR 使用 ASE。文件格式由工具入口限定，材料名称本身不代替确定结构。

初始速率拟合要求明确浓度列、速率列及单位；Excel 多表时指定工作表。可选给出速率标准差，分组分别拟合，条件列在组内保持一致。输入是已获得的初始速率，不直接将吸光度时间序列作为速率。重复点保留；图件、参数、原输入、报告和复跑代码形成一项成果。

内置图表使用统一白底、分类色、数学上下标与单位，提供 SVG 和高分辨率 PNG。结果预览读取保存的数值／图件／结构，不因打开页面重新拟合或提交计算。

## 数据来源与证据

### 项目文件

在“项目面板 → 全部文件”定位本地科研资料，再到“权限”授权 Agent 读取。CSV、TSV、XLSX 可用于校准等表格分析，CIF、XYZ 等结构文件可用于结构核对，PDF、DOCX 可用于文档读取。根据任务选择支持该格式的工具。从其他数据库导出的表格也可以按这个方式使用。

### 文献证据

文献证据使用 `highzyme.evidence.v1`。`highzyme_evidence_save` 保存通过结构检查的草稿，`highzyme_compare_evidence` 比较 2–12 条选定测定，保留单位差异、多值、条件缺失与冲突。

## 案例研究与验证反馈

应用方向探索关注材料的催化作用、目标对象、识别／选择性、信号链和干扰；材料设计关注具体组成、位点、配位、表面、载体或形貌变化。两者共用主控、计划、工具、成果和版本。

研究流程保存目标、约束、候选、固定版本证据、未知项，以及验证方法、对照和判据。`highzyme_candidate_check` 只对明确提供的组成、计量和氧化态检查电荷等一致性；不凭名称生成吸附能、稳定性或活性数值。材料家族规则按反应、配位、自旋和条件使用。

候选采用稳定 `candidate_id` 和内容版本。支持的本地分析、通用计算与 QE 准备可关联验证问题和判据；取得结果后记录 supports／contradicts／inconclusive，并关联实际结果成果及其 Git 版本。旧方案的结果继续保留在对应方案版本下。材料候选可用 `parent_candidate_id` 承接同案例的应用候选。

## 可选外接计算

在“工具与计算资源 → 计算资源”添加 SSH/Slurm 或兼容 HTTP 服务。配置助手打开普通会话，帮助检查连接、队列、工作目录、软件模块和程序路径。它复用新会话默认模型，已有草稿和在办任务保持原状。

SSH 使用本机 OpenSSH 配置、私钥或 SSH agent、known_hosts。主机指纹和加密私钥由本机 SSH 工具处理；密钥正文不提交给模型。远端登录节点需要 Python 3.6+、tar 和 Slurm，QE 计算节点使用 Shell/MPI，不需要部署 mat-agent 服务。

先“检查环境”，确认可写工作目录、队列／账号及所需程序，再启用资源与外接计算权限。启用状态在应用重启后需要重新检查。Slurm 可提交不等于 QE 或全部后处理程序已就绪。

| 方法 | 主要内容与额外要求 |
|---|---|
| SCF、结构／晶胞优化 | `pw.x`，明确结构、UPF、截断能、k 点、约束与磁矩 |
| 截断能／k 点收敛 | 比较给定序列及判据，保留各步能量 |
| 吸附、结合与形成能 | 明确参考态和系数，元素守恒；不自动处理带电缺陷修正 |
| DOS／PDOS／能带 | `dos.x`、`projwfc.x`、`bands.x` 及相应输入 |
| 差分电荷／Bader | `pp.x`，分量结构、晶胞与网格匹配；全电子密度需 PAW，Bader 程序由用户资源提供 |
| 反应能／自由能 | 区分电子能、振动和温压校正，保留虚频检查与参考态 |
| NEB／CI-NEB | `neb.x`，一致原子顺序、晶胞与端点，检查路径收敛 |

单项计算使用 `highzyme_qe_prepare`，多步骤 JSON 使用 `highzyme_qe_workflow_prepare`。准备只生成输入与请求；检查后按同一 `job_id` 提交、查询、取消和取回结果。修改输入需要重新准备。

默认规格为 1 个 MPI 进程、1 个线程、1024 MiB、300 秒，可在资源设置中调整默认值和上限。时限约束队列占用及失控任务，正常完成会提前结束。实际规格仍受用户队列限制。

后台核对已提交任务，重启后按原任务编号继续查询，不自动重复提交。停止对话不等于取消远端任务；结果下载失败可重试取回而不重算。调度完成、电子收敛、结构收敛与文件取回分别保存。持久本机终端只保留当前服务运行期间的进程状态。

当前直接支持 SSH/Slurm/QE 和兼容 HTTP 连接；PBS／LSF 等没有直接调度适配。计算软件和赝势由用户资源或明确来源提供。输入字段见[科学计算技能](../integrations/deepseek-harness/foundation/skills/scientific-computing/inputs.md)，小输入见[QE 示例](../examples/general-research/qe-methods/README.zh-CN.md)。

## 保存位置与交付

```text
用户项目/
  .git/                              文件版本
  .highzyme/                         索引、权限、任务、记忆和引用缓存
  artifacts/<discussion-keywords>/    普通会话成果
  cases/<keywords>-<short-id>/        案例资料与研究内容
    artifacts/                       案例成果
  inputs/ 或其他用户目录/             研究输入

本程序 runtime/foundation/home/        模型连接、会话和本机运行配置
```

项目文件直接在用户选择的目录中读写。既有路径不自动改名；修改已有成果更新同一路径并用 Git 记录。项目记忆、权限、任务缓存与运行配置按各自规则排除 Git，不能只用项目 Git 代替这些状态的备份。

## 必要检查与试用

在程序根运行 `scripts/check_foundation.py` 进行离线软件与数值检查。具体命令见[程序首页](../README.zh-CN.md)。

手动试用可依次进行：配置默认模型 → 添加研究项目 → 复制并拟合合成初始速率 → 查看整组成果 → 整理一轮讨论 → 新建案例并引用成果版本 → 修改原成果并核对固定引用 → 查看版本差异与恢复 → 按需试用归档、记忆和计算配置。

合成输入的预期值与每步观察点见[示例说明](../examples/general-research/README.zh-CN.md)。模型整理质量使用用户选择的模型检查；外接计算需用户连接和授权后才执行。
