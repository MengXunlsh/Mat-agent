# Research workflow references

Checked 2026-11-03 through publisher/preprint pages and official repositories. We adapt design principles to the existing Harness runtime; no upstream framework or simulation infrastructure is installed.

- **Coscientist**, Autonomous chemical research with large language models, Nature (2023), https://doi.org/10.1038/s41586-023-06792-0 ; https://github.com/gomesgroup/coscientist . A planner selects retrieval, documentation and execution capabilities and adapts using returned observations. Used here for task-driven tool selection and result feedback, not mandatory fixed-stage execution.
- **ChemCrow**, Augmenting large language models with chemistry tools, Nature Machine Intelligence (2024), https://doi.org/10.1038/s42256-024-00832-8 ; https://github.com/ur-whitelab/chemcrow-public . Expert tools supply chemical operations and observations to the language-model agent. Used here to separate deterministic numerical checks from generated interpretations.
- **AtomAgents**, https://github.com/lamm-mit/AtomAgents ; https://arxiv.org/abs/2407.10022 . Specialized collaboration combines retrieval, physical simulation and analysis. Used here for bounded creator/reviewer assignments over existing native research roles.
- **MASTER**, Hierarchical Multi-agent Large Language Model Reasoning for Autonomous Functional Materials Discovery, arXiv:2512.13930 (preprint, 2025), https://arxiv.org/abs/2512.13930 . Separates higher-level candidate reasoning from atomistic simulation and compares peer-review/triage strategies. Used here for candidate review and keeping reasoning separate from optional resource execution; not a claim to reproduce its learning algorithm or performance.
- **Latent materials knowledge**, Unsupervised word embeddings capture latent knowledge from materials science literature, Nature (2019), https://doi.org/10.1038/s41586-019-1335-8 . Motivates exploring material–application relationships. mat-agent currently uses its registered group-descriptor similarity analysis, not the paper's word-embedding model. Dataset novelty and performance remain separate from similarity.

Primary retrieval came from web search and official project pages. Some direct Nature full-page opens redirected to inaccessible publisher authentication; only available primary-page extracts and repository content were used. These sources guide workflow design, not the scientific evidence for an individual candidate.
